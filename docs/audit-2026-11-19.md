# 文档与实现审计（2026-11-19）

## 结论

V1/P0 与主要 P1 功能已闭环；数据库、接口、页面和权限口径已对齐。
本轮补齐单篇资料问答、插件默认范围、标签管理、管理端重置密码、Webhook 告警、RAG 评测质量指标和 ingest_tasks 入库任务；
剩余项主要是评测集内容、邮箱验证、OCR、测试体系和部署运维，不影响当前 V1 主链路。

## 2. 表 → 接口

- 用户侧资源接口均带 `user_id` 归属过滤。
- 标签新增/编辑/删除、文章标签关联、问答取消/反馈、个人用量导出均已接入。
- 管理端模型、系统设置、预算、Webhook 测试、用户配额/状态/密码重置、导入/任务操作、审计、评测均有接口。
- `user_plugin_settings` 通过 `GET/PUT /users/me/plugin-settings` 闭环，`default_scope_id` 指向本人文件夹或标签。
- `ingest_tasks` 由 article 入库链路写入，管理端通过 `GET /admin/api/v1/ingest-tasks` 只读查看。
- `message_feedback` 通过 `POST /messages/{id}/feedback` 闭环，消息列表返回反馈状态。

## 4. 权限与安全

- 用户和管理员 token 分离，audience 不同。
- 所有用户资源查询/写入带归属校验。
- 管理员接口统一经过 `AdminJwtAuthFilter`，并叠加 60 次/分钟操作限流。
- SSRF、提示词注入、文件类型/大小、API Key 掩码、CORS 白名单已接入。
- 密码修改撤销全部用户 refresh token。
- API Key 存 `system_settings`（`is_secret=1`，管理端只返回掩码）；生产环境应限制 DB 权限。

## 5. 已修复的文档/实现偏差

1. 用户设置页原型包含模型/预算等管理员能力，与权限边界冲突；实现按 API/需求拆分为用户资料/插件偏好，模型/预算放管理后台。
2. `citation score` 在启用 rerank 时明确为 relevance score。
3. `/articles` 的 `folders` 字段与 `folderId` 筛选已从“后续”改为已实现。
4. 标签编辑、问答取消/反馈、个人 CSV 导出从 P1 标记改为已实现。
5. 评测接口补充 `userId`，与 `rag_eval_*` 表的归属字段一致。
6. 新增 40501 `METHOD_NOT_ALLOWED`，避免错误方法返回 500。
7. Embedding 调用补记 `ai_usage.scene=EMBEDDING`，token 计入月度用量。
8. 分钟限流抽出 `MinuteRateLimiter`，认证/问答/上传/书签导入复用。
9. CSV 转义抽到 `common.util.Csv`，用户端与管理端复用。
10. 预算告警改用 Webhook，管理端可测试；原型设置页补充 Webhook 字段。
11. 告警 Webhook URL 在保存时校验 http/https，发送日志只记录 host。
12. 单篇资料问答在 ChatView 补齐；插件按 `defaultScopeId` 发送 FOLDER/TAG 范围。
13. 标签管理 UI 接入重命名、改色、删除；删除标签同时移除资料关联。
14. 管理端新增用户密码重置，重置后撤销全部 refresh token。
15. 插件设置新增 `default_scope_id`，迁移文件 `V003__plugin_default_scope.sql`；`GENERAL` 已作为通用问答模式开放。
16. RAG 评测补齐回答生成、引用准确率、LLM-as-judge 正确率、延迟和成本；迁移 `V004__eval_answer_details.sql` 保存回答与判定说明。
17. `ingest_tasks` 接入上传/手动/URL/重建索引链路，管理端新增只读资料入库任务列表。
18. 资料入库异常按错误码映射：URL/文件类型/文件过大/解析失败/向量化失败不再统一返回 500。
19. 新增数据清理任务：过期 refresh token、extension code、idempotency key 和结束超过 30 天的入库任务；分批删除，可配置。
20. 新增 `ai_usage_daily` 日汇总任务，默认每天回补最近 7 天，聚合调用数、tokens、成本、平均延迟和错误数。
21. 两个服务暴露 Prometheus 指标；新增 Windows/Linux 备份脚本和恢复说明。
22. 新增 Prometheus 抓取配置和告警规则：5xx、P95、Chat AI 错误率、预算 Webhook 失败。
23. 新增 Playwright 登录 E2E 和 k6 基础压测脚本，CI 增加 Playwright job。
24. 重做登录页：桌面双栏品牌叙事、动效光晕/网格/悬浮球、表单切换指示器和移动端单列布局。
25. 上传 PDF 支持可选 Tesseract OCR：正文过短时渲染页面并调用 `tesseract`，默认关闭；缺失命令返回明确错误。
26. 插件升级到 1.0.0：补图标、可配置 HTTPS 后端与按需 host 权限、popup 连接状态、网页端入口、打包脚本和上架说明。
27. 通用问答模式接入 `POST /chat/stream`：`scope.type=GENERAL`，不检索资料库、不返回引用；Web 和插件均可选择。
28. 多轮检索改写：当前问题较短或依赖上下文时，拼接最近用户问题再检索；新增 `ConversationQueryRewriter` 和单元测试。
