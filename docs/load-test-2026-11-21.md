# 负载测试记录（2026-11-21）

## 环境

- 入口：`https://localhost/api/v1`（Caddy + user-web nginx + user-api）
- 部署：Docker Compose + `docker-compose.https.yml`
- 数据库：MySQL 8.4（Docker）
- 数据集：
  - 1 个压测用户
  - 2,000 篇资料
  - 6,000 个切片
- 压测脚本：`scripts/load-test.mjs`
- 并发：20 VUs
- 时长：20 秒
- 请求路径：
  - `GET /articles?page=1&pageSize=20`
  - `GET /articles/stats`
  - `GET /teams`

## 说明

- 这次压测覆盖的是**认证后的资料列表、统计和团队列表**，包括 Caddy TLS、nginx 反向代理和 MySQL 查询。
- 没有压测 Chat/RAG：Docker 部署使用 `AI_ENABLED=false` 和 dev embedding，避免外部模型成本和不确定性；AI/RAG 压测需要单独准备 mock 模型或预算。
- 2,000 篇/6,000 切片是本地构造数据，不是真实用户数据；用于验证列表和统计在数据量上来后的基本表现。
- 复现命令：

```powershell
$env:NODE_TLS_REJECT_UNAUTHORIZED='0'
$env:BASE_URL='https://localhost/api/v1'
$env:EMAIL='load-user@shiye.local'
$env:PASSWORD='LoadTest123'
$env:VUS='20'
$env:DURATION='20s'
node scripts/load-test.mjs
```

> 压测数据在 Docker 演示库中；本地开发库已清理。生产压测应使用独立环境，不要污染业务库。
